# NEXORA build outcomes

The user requests reasonable defaults and uninterrupted build of a P0 vertical slice. Full requirements are preserved in docs/MASTER_PROMPT.txt and expanded clause-by-clause in the manifest/roadmap; unfinished items remain open.

- [ ] Interactive attributed map, manual origin and destination: guest can open map, deny GPS and still search/manual-origin; allow permission later; trip ends and tracking stops. Pan/zoom, map pin selection, recenter and scale work. Rotation/pitch/3D remain explicitly unavailable if renderer cannot support them. No invented imagery or businesses.
- [ ] Search and provider states: known London address/postcode returns actual configured-provider results with attribution; invalid query yields a useful empty state; no key yields clearly labelled demo/setup state. Public Nominatim is not an unrestricted autocomplete API. Coordinate bounds validated. Permission, loading, empty, error and offline states disclosed.
- [ ] Route preview: calculate route between test points using a configured test provider; geometry and instructions derive from engine. Alternatives only if distinct/returned. Driving/walking/cycling only use verified profiles. Manual origin and travel-mode switching, route comparison, route lock and Start simulation work. Costs, reliability, traffic and legal restriction coverage unknown when missing, never zero or fabricated.
- [ ] Stable route decisions: deterministic configurable/versioned weights 0.50 duration, 0.20 reliability, 0.15 cost, 0.15 simplicity, renormalised over known dimensions. Default improvement threshold max(180 seconds, 10% remaining time), repeated stable improvements, 90 second cooldown/hysteresis. Route lock applies to soft improvements; verified closure/legal infeasibility/genuine off-route override. Single unverified incident cannot force closure. Poor GPS requires uncertainty and consistent samples before off-route.
- [ ] Simulator and trip completion: explicit idle/planning/preview/navigating/degraded/offline/rerouting/arrived/ended states. Simulator shows synthetic/engine-derived position, deterministic instructions/progress and arrival; inject tunnel/drift/offline/closure and recovery. No native road guidance enabled before device validation. No keyboard/forms while playback moving; minimal driving focus without bottom tabs. Mute/end/recenter respond honestly.
- [ ] Local guest data: saved places persist, home/work assignment, trip history opt-in, planned route retention minimal. Privacy preferences, appearance/light-dark, units, export/delete local guest data. No default upload of exact traces; no registration wall; no pretend sharing/sync.
- [ ] Test community: manual report/confirm/not-there, compatible dedupe, expiry/moderation, bounded rate limit and clear demo-only source. No demo incident reaches live services. Local moderator test environment explicitly distinct from protected real admin console; production admin endpoints deny anonymous requests.
- [ ] Provider status/offline: capabilities visible, unavailable features explain prerequisite and do not look working. No live reports available where no data; no live traffic/speed-limit/cost claims. Full offline graph gate blocked; never bulk-download public tiles. Cached route visibility is not offline routing.
- [ ] Delivery evidence: automated typecheck/lint/unit/integration commands and actual outputs, known failures, read-only validation agent, screenshots of implemented screens, real iOS/Android manual device plan. Original icon + source + dependency lockfile + .env.example + setup guide + provider comparison/licence register + privacy/security/legal drafts + moderation procedures + phased status manifest covering every feature. Native road-use/background/offline/car-display gates blocked until real validation. No production readiness claim, release build, purchase or publication.
